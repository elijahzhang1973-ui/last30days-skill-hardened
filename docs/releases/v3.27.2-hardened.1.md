# v3.27.2-hardened.1 release facts

This hardened release is based on upstream tag `v3.27.2`, commit
`267d50f7fcbab8a6457a93ad6ca15cbc199f633c`, and tree
`c2964132f3167cac73be03cf378bb74893492885`.

## MCP tool surface

The MCP server exposes two tools: `preflight` and `research`. Describing it as
a single-tool server is incorrect. `preflight` is the secret-free permission
and capability inspection contract; `research` invokes the bounded research
engine.

## WebSearch incident scope

The historical issue associated with the trailing `Sources` section concerned
the host WebSearch citation contract adding a trailing source list; see
[upstream PR #1250](https://github.com/mvanhorn/last30days-skill/pull/1250)
and its fixed merge commit
[`77e42dd`](https://github.com/mvanhorn/last30days-skill/commit/77e42dd).
That change did not prove runtime process isolation, current-host subagent
availability, or a one-tool MCP architecture. The hardened Codex contract
therefore treats WebSearch results as untrusted data and does not describe
prompt guidance as a security sandbox.

## Platform scope

Only Linux Skill/Python and Linux amd64 MCPB may become release-supported after
the exact candidate passes G5. Windows and macOS source remains in the tree,
but this version does not publish support claims for those hosts. See
`PLATFORM_SUPPORT.md` for the static scope and reopening conditions.
